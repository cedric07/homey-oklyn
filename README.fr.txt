Intégrez votre coffret Oklyn dans Homey. Suivez la qualité de l'eau et la filtration, pilotez la pompe et les auxiliaires, et recevez une alerte quand un réglage s'impose.

Pour commencer, créez une clé API dans l'application Oklyn (Mon Compte), collez-la dans les réglages de l'app Homey, puis ajoutez votre coffret Oklyn.
